# Особисті фінанси

Курсовий проєкт з дисципліни «Конструювання програмного забезпечення».

- **Автор:** Цебенко Володимир Володимирович, група ІС-23-01
- **Керівник:** Ковальчук В. Я.
- **Тема:** № 22 «Особисті фінанси»
- **Рівень складності:** ІІІ — достатній (7–9 балів)

## Призначення

Вебзастосунок для обліку особистих грошей: рахунки (готівка, картка, скарбничка), категорії доходів і витрат та журнал операцій. Під час проведення операції баланс рахунку змінюється автоматично, а витрату, більшу за наявні кошти, програма не проводить.

Усі дані в проєкті — вигадані навчальні.

## Функції

| Код | Функція |
| --- | --- |
| ФВ-01 – ФВ-04 | Перегляд, додавання, редагування та видалення рахунків (заборона видалення рахунку з операціями) |
| ФВ-05 – ФВ-08 | Перегляд, додавання, редагування та видалення категорій (заборона видалення категорії з операціями) |
| ФВ-09 | Журнал операцій |
| ФВ-10 | **Проведення доходу або витрати з перевіркою достатності коштів на рахунку** |
| ФВ-11 – ФВ-12 | Редагування та видалення операції з перерахунком балансу |
| ФВ-13 | Пошук операцій за коментарем або категорією |
| ФВ-14 | Фільтрування за типом, рахунком, категорією та періодом |
| ФВ-15 | Сортування за датою або сумою |
| ФВ-16 – ФВ-17 | Перевірка введення, повідомлення про недоступність сервера |

Головне правило: **витрату можна провести, лише якщо `сума ≤ баланс рахунку`**. Детальна постановка — у [docs/task.md](docs/task.md).

## Запуск

Потрібні: Node.js LTS, VS Code з розширенням Live Server.

1. Відкрийте папку `course-project` у VS Code і термінал **Terminal → New Terminal** (термінал має бути відкритий саме в цій папці).
2. Встановіть залежності (один раз):
   ```
   npm install
   ```
3. Запустіть JSON Server і не закривайте цей термінал:
   ```
   npx json-server --watch db.json --port 5000
   ```
   Перевірка: у браузері відкрийте `http://localhost:5000/accounts` — має показатися масив рахунків.
4. Клацніть правою кнопкою по `index.html` → **Open with Live Server**.

Щоб Live Server не перезавантажував сторінку після кожного запису в `db.json`, створіть файл `.vscode/settings.json`:

```json
{ "liveServer.settings.ignoreFiles": [".vscode/**", "db.json", "package.json", "package-lock.json", "node_modules/**", "docs/**", "**/*.md"] }
```

## API (JSON Server)

| Дія | Метод | Адреса |
| --- | --- | --- |
| Список | GET | `/accounts`, `/categories`, `/transactions` |
| Один запис | GET | `/accounts/1` |
| Створення | POST | `/transactions` |
| Оновлення | PATCH | `/accounts/1` |
| Видалення | DELETE | `/transactions/1` |
