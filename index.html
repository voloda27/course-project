Сімейний бюджет

Курсовий проєкт «Особисті фінанси» · навчальні дані

Оберіть сторінку

Обидві сторінки працюють з одними даними через JSON Server. Вхід і ролі не передбачені — це дві частини інтерфейсу, а не захист доступу.

Член родини Переглянути рахунки родини, подати заявку на витрату, перевірити її статус або скасувати. Власник бюджету Схвалювати й відхиляти заявки, керувати рахунками й категоріями, вести журнал доходів і витрат.

Перед роботою

У терміналі в папці проєкту запустіть JSON Server і не закривайте його:

npm run server — API на http://localhost:5000

Сторінки відкривайте через Live Server (адреса на кшталт http://127.0.0.1:5500/), а не подвійним кліком по файлу.
